# 🌸 PAUSE V2

PAUSE is an AI-powered emotional wellness companion designed to help users reflect, check in with their emotions, and build healthier daily habits through mindful conversations.

## Goals
- Daily emotional check-ins
- AI conversation coach (Echo)
- Personal reflection journal
- Mood insights
- Progress tracking

- CSS
